# PieLord757's Homebrew tap

```bash
brew install --cask pielord757/tap/claude-pet
```

| Cask | What it is |
| --- | --- |
| [`claude-pet`](Casks/claude-pet.rb) | [Claude Pet](https://github.com/PieLord757/claude-pet): a floating pixel pet that shows which Claude Code chats are working, need you, or just finished |

Update with `brew upgrade --cask claude-pet`; remove with `brew uninstall --cask claude-pet` (add `--zap` to also remove its settings and imported pets).
